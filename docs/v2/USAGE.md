# 使用

## 基本用法

绑定成功后，App 首页就是与电脑的对话界面，和平时用聊天工具体验一致：

- 输入一句话，点发送
- AI 在电脑上执行，过程与结果实时回到手机
- 需要文件时可以让它读取电脑上的文件

**不建议同时用桌面端和手机端操作同一个任务**——手机有独立会话，但两边同时改动同一批文件容易互相覆盖。

---

## 连接状态怎么看

App 首页与详情页会显示当前状态：

| 显示 | 含义 |
|---|---|
| 在线 | 连接正常 |
| 正在连接 / 正在重连（第 N 次） | 正在尝试，通常数秒内恢复 |
| 离线：消息会排队等连接 | 消息已保存，连上后会自动发出 |
| 连接失败 | 需要人工处理，见下方「常见问题」 |

详情页的「当前地址」会显示正在使用的通路（公网隧道 / 局域网）。

## 高级连接方式

常规情况**不需要**打开这些开关。它们位于「设置 → 高级连接方式」。

| 开关 | 什么时候用 |
|---|---|
| 允许局域网直连 | 手机和电脑在同一个 Wi-Fi，且该网络允许设备互相访问 |
| 内部测试模式 + USB 调试通道 | 公网隧道不可用，需要临时用数据线连接时 |

> 「USB 调试通道」只有打开「内部测试模式」后才会出现；关闭内部测试模式会同时关闭它。

### 用 USB 数据线连接（应急）

```bash
# 电脑上执行，建立端口转发
adb reverse tcp:19387 tcp:19387
```

手机：设置 → 高级连接方式 → 打开「内部测试模式」→ 打开「USB 调试通道」。

> 数据线插拔或 adb 重启后，转发规则会失效，需要重新执行上面的命令。

## 文件

- 可以把手机里的文件发给电脑上的 AI（单文件上限 8 MB）
- 可以让 AI 生成文件并在手机上查看/保存
- 下载上限 48 MB；更大的文件请在电脑上处理

## 常见问题

### 扫码提示「二维码已过期」

配对密钥有 10 分钟有效期。在电脑上刷新 `http://127.0.0.1:19387/openwhale` 重新生成即可。

### 扫码提示「内容不是有效对象」

你扫的是普通网址，不是配对二维码。请扫描电脑上 `/openwhale` 页面里显示的那张二维码。

### 一直显示「正在连接」

1. 确认电脑上的插件还在运行（`/openwhale/health` 能访问）
2. 如果曾经重启过 DSH 或插件，公网隧道的域名可能已经变了 —— 重新扫一次二维码
3. 仍然不行时，用数据线按上面的「USB 数据线连接」步骤临时接上，连上后会自动更新地址

### 提示「此电脑已绑定另一台手机」

一台电脑只能绑定一台手机。要换手机，请先在原手机的「详情 → 解绑这台电脑」解除绑定。

### 手机息屏后断开

系统会冻结后台应用。把 App 切回前台即可自动重连；充电时可开启「保持唤醒」避免休眠。

## 隐私与安全

- 设备私钥保存在系统安全区（Android Keystore / iOS Keychain），不上传、不可导出
- 电脑端只保存设备**公钥**
- 配对密钥一次有效、10 分钟过期
- 电脑只主动出站连接，不在公网开放任何端口
